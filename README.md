# Simulados da Ana e Dani — Ciências Humanas

> para estudar ouvindo Anavitória 🎧

Aplicativo/PWA de simulados de Ciências Humanas com Sociologia, Filosofia, História e Geografia.

## Publicação

A versão final do aplicativo é distribuída neste repositório como o arquivo:

`Simulados_Ana_Dani_Humanas_FINAL_PWA.zip`

O workflow `.github/workflows/deploy-simulados.yml` descompacta esse pacote e publica somente o conteúdo da PWA no GitHub Pages.

## Instalação no celular

Depois da publicação no GitHub Pages:

- Android/Chrome: abrir o link e usar **Instalar** / **Adicionar à tela inicial**.
- iPhone/iPad/Safari: **Compartilhar → Adicionar à Tela de Início**.

## Histórico do repositório

Este repositório antes continha o experimento `question-audit-pipeline`. O estado anterior à conversão foi preservado em branches de arquivo e no histórico Git; portanto, nada antigo foi perdido de forma irreversível.

O projeto é separado do repositório principal do Sociosofia.
